# MMSELL settlement-taxonomy repair — the review, prefix by prefix

Companion to `CENSUS_AND_MANIFEST_20260824.md` (the frozen batch) and
`EVIDENCE_20260824.txt` (Kalshi's own titles and rules text, verbatim, for all 198).
The platform-impact analysis is in `PLATFORM_IMPACT_20260824.md`.

**Nothing here was decided by looking at arm economics, P&L, treatment effects or model
residuals.** Those were not opened during the classification pass, and the census was not
recomputed between prefixes.

---

## 1. The discriminator, stated before the case-by-case

`settle_mode` is the axis an entry-timing rule has to respect, so the question each prefix was
put to is *what has to happen before this contract can resolve*:

| mode | the test applied |
|---|---|
| `scheduled` | settlement is a figure **published by a named external source**, and resolution cannot happen before that publication instant |
| `discrete` | resolution turns on an **occurrence inside a window**, whenever it occurs; no publication instant is waited on |
| `in_play` | resolution comes through a **live contest**, progressively revealed by play |
| *(absent)* | the documents do not decide, or the prefix cannot be added safely — stays `unknown`, admitted by no `mode=`/`mtype=` book |

Writing the test down first is what keeps the long tail consistent: the same rule decides
KXHORMUZWEEKLY (a weekly count that waits for IMF PortWatch) and KXYTVIEWSW (a threshold that
resolves the moment any daily value crosses it) without either being argued to fit a target.

## 2. Evidence rules actually applied

- **Strong evidence** is Kalshi's published title + rules text. Kalshi's `settlement_source`
  field is **empty for all 1,561 documents** in this population, so it decided nothing here —
  not because it was ignored, but because it was not there.
- **Weak evidence** — median |expiration − close| (`GAP`) and the share still quoting 15–85¢ at
  the last tick (`PATH`) — corroborates only. It never decided a prefix and never vetoed a
  strong text. Where it disagreed, the disagreement is written into the row.
- **A bare clock time decided nothing.** "the game originally scheduled for Aug 23, 2026 at
  4:10 PM EDT" is a *start* time; it appears on MLB total-bases, KBO baseball, Valorant and
  LNBP basketball, all of which are `in_play` below.
- **`can_close_early` decided nothing.** It is set on 100% of this population, index-close
  markets included. `classify()` takes a series string and nothing else, so the flag cannot
  reach it — asserted structurally in
  `tests/test_mmsell_taxonomy_repair_20260824.py::test_can_close_early_has_no_vote_because_it_is_not_an_input_at_all`.
- **Month-long instruments were not swept into `scheduled` by their duration.**
  `KXBRENTMON`, `KXGOLDMON` and `KXH200MS` are `scheduled` because their text names the
  settlement instant or publisher; `KXBNBMINMON`, a month-long crypto-adjacent barrier, is
  **`discrete`** on the same evidence rule. The duration was never the reason.
- **No catch-all.** Every accepted prefix is ≥5 characters, and an unmatched series still
  returns `("unclassified", "unknown")`.

## 3. Second independent review pass

Every prefix classified as **`scheduled`** or **`discrete`** — 31 and 19 respectively, the
50 that decide which arm a market enters — was re-read against Kalshi's text a second time,
independently of the first pass, together with every boundary case flagged in column 8. The
in-play sports rows were re-read as a class against the template sentence they all share
("wins / over N / by more than N ... in the ... game originally scheduled for ..."), with each
prefix checked individually against that template rather than assumed into it.

Two boundary calls the second pass **changed**, and one it **kept**:

- `KXYTVIEWSW` / `KXYTVIEWSHIGH` — the audit's rules regex reads "at any point during" as
  `in_play`. Changed to **`discrete`**: there is no contest, and resolution does not wait on a
  publication. This moves 31 markets to the **control** side, the conservative direction.
- `KXBNBMINMON` — first read as a monthly price strike (`scheduled`). Changed to
  **`discrete`**: "is EVER below $550.00 ... at each minute a settlement value is calculated"
  is a barrier touch, not a print at an instant.
- `KXTRUMPACT` — **kept** `scheduled` after re-reading, and flagged: the actions are visible
  during the week, so something is revealed early, but settlement waits for a reading of a
  named page at a stated instant. This is the single row most worth a reviewer's disagreement;
  it is 2 markets and the gate does not turn on it.
